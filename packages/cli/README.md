# Cache CLI

Cache is a local-first code snippet library. Your snippets live in SQLite on
your machine and remain available from the terminal or the local web app.

```bash
npm install --global https://github.com/tanRdev/codecache/releases/latest/download/codecache-cli.tgz
cache init
cache add ./use-auth.ts --tag react
cache search auth
```

The complete documentation and source are available at
[github.com/tanRdev/codecache](https://github.com/tanRdev/codecache).
